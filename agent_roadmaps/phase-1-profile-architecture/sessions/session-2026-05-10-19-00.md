## Decisions Made

1. **Selector Syntax**: Kept it simple for Phase 1 with two forms:
   - Equality: `axis=value`
   - List membership: `axis in [value1, value2]`
   - No AND/OR operators yet (can be added in Phase 2 if needed)

2. **Precedence**: `when` selector takes precedence over legacy `project_types` field to enable gradual migration

3. **Conservative Fallback**: If profile detection fails, allow the entry (return True) rather than blocking it

4. **Axis Coverage**: Implemented evaluation for all six profile axes, even though Phase 1 only uses language and build_system
