# /navigate

Code navigation. The canonical, vendor-neutral procedure body lives at
[`.ai/skills/navigate/SKILL.md`](../../../.ai/skills/navigate/SKILL.md).

## Commands

- `/navigate find <symbol>` — locate definition
- `/navigate uses <symbol>` — find all references
- `/navigate deps <file>` — show file dependencies
- `/navigate arch` — analyse repository architecture
- `/navigate calls <function>` — show call graph

When this slash command is invoked, also read
[`.ai/skills/navigate/SKILL.md`](../../../.ai/skills/navigate/SKILL.md) for
the full behavioural spec.
